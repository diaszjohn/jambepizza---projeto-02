# 🍕 Jambe Pizza

Um sistema web moderno, responsivo e intuitivo desenvolvido para uma pizzaria, permitindo que os clientes naveguem pelo cardápio, personalizem pedidos e enviem o carrinho diretamente para o atendimento via **WhatsApp**.

## ✨ Funcionalidades

* **Cardápio Interativo:** Categorias organizadas (Pizzas Salgadas, Doces, Bebidas e Combos).
* **Sistema de Carrinho:** Adição, remoção e atualização dinâmica de itens com cálculo automático do valor total.
* **Integração com WhatsApp:** Geração automática de uma mensagem formatada com os itens do pedido, endereço de entrega e forma de pagamento para agilizar o atendimento.
* **Design Responsivo:** Otimizado para funcionamento perfeito em smartphones, tablets e computadores.
* **Interface Moderna:** Visual limpo e atraente com foco na experiência do usuário (UX).

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web essenciais, priorizando performance e simplicidade:

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização customizada, animações fluidas e design responsivo (Flexbox / CSS Grid).
* **JavaScript (ES6+):** Lógica do carrinho de compras, manipulação do DOM e integração com a API do WhatsApp.
* **Fontes & Ícones:** Google Fonts e Font Awesome.
